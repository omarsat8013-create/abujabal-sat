# Android build (قشرة التطبيق)

الـAPK قشرة WebView بسيطة: بتفتح `https://omarsat8013-create.github.io/abujabal-sat/index.html?app=36&t=<timestamp>`
(علامة الوقت بتخلي كل فتحة عنوان جديد، فأي كاش قديم بيعمل miss)، وفيها نسخة كاملة من الويب
مضمومة في `assets/www` كخطة بديلة لو النت قطع.

## البناء
محتاج JDK 17 + Android build-tools 34 + platform android-34:

```bash
REPO=/path/to/abujabal-sat KS=/path/to/release.jks KSPASS=... ./build.sh
```

`build.sh` بيجمع `assets/www` من المستودع، ويستبدل مسارات `dl/` بالمسارات المطلقة، ويبني ويوقّع.

## مهم: مفتاح التوقيع
مفتاح الإصدار القديم (CN=AbuJabalSat، بصمة SHA-256 تبدأ 4E:66:98:EA) ضاع مع الوكيل اللي بنى
النسخ 3.1.1–3.1.4. النسخة 3.1.6 موقّعة بمفتاح جديد (بصمة ec2ced5c…)، وده معناه إن التحديث
فوق النسخة القديمة محتاج **إزالة التطبيق القديم الأول** (أو تثبيت بحزمة مختلفة).
لازم نحفظ المفتاح الجديد في مكان دائم قبل أي بناء جديد.
